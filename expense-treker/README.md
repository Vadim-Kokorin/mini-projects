# Трекер расходов

Это приложение, чтобы записывать свои траты. Оно считает общую сумму и показывает, сколько денег ушло на каждую категорию.

## Что умеет:
- Добавлять расходы (категория, сумма, дата).
- Удалять расходы.
- Считать общую сумму.
- Считать сумму по каждой категории.
- Сохранять данные в браузере (чтобы не пропадали при обновлении страницы).

## Сделано на:
- HTML
- CSS
- JavaScript (чистый, без библиотек)
- localStorage (для сохранения данных)
